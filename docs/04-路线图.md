## 贡献指南

本项目**零构建**，贡献门槛极低：

1. 改代码 → `chrome://extensions` 点刷新 → 立即生效
2. 跑 `node scripts/verify-e2e.mjs` 确认没破坏功能（36 项）
3. 跑 `node scripts/verify-mcp.mjs` 确认 MCP 链路正常（15 项）

新增一个工具只需三步：

1. 在 `shared/tools.js` 写 JSON Schema 描述（**记得写清「什么时候该用」**）
2. 在 `background/handlers.js` 实现同名 handler
3. 在 `scripts/verify-e2e.mjs` 补一条断言
